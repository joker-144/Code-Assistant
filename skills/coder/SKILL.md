# Agentic Coding — 全自动 AI 编程工作流

来源: SkillHub | v1.0.0

## 概述

编排从"想法"到"PR"的完整 AI 编程流程。人只在 4 个关键节点把关，其余环节 AI 自主完成。

**4 个人工检查点：**
1. 确认需求（PRD）
2. 选定技术方案
3. 判断测试充分性
4. Review PR → Merge

## 任务分级

| 规模 | 判断标准 | 执行流程 |
|------|---------|---------|
| **小** | 修 bug、改样式、< 50 行改动 | 直接实现 |
| **中** | 一个完整 feature | 需求发现 → 技术设计 → 实现 |
| **大** | 多模块、新项目 | 完整深度发现 → 技术设计 → 分任务实现 |

## 工作流程

### 第一步：任务分级
根据用户描述判断任务规模，选择对应流程。

### 第二步：需求发现（人工检查点 ①）
- 确认做什么、关键取舍、不做什么
- 用户确认后继续

### 第三步：技术设计（人工检查点 ②）
- 技术选型、架构设计、模块划分
- 用户确认后继续

### 第四步：编码实现
- 按模块逐步实现
- 编写单元测试
- 持续集成验证

### 第五步：测试验证（人工检查点 ③）
- 运行全部测试
- 检查覆盖率
- 用户确认测试充分性

### 第六步：PR 提交与审查（人工检查点 ④）
- 生成 PR 描述
- 提交代码审查
- 用户 Review → Merge

## 检查清单

- [ ] 需求已明确并确认
- [ ] 技术方案已选定
- [ ] 代码实现完成
- [ ] 单元测试通过
- [ ] 无安全漏洞
- [ ] PR 已提交
