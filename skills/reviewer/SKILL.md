# 代码审查工具

来源: SkillHub (原作者: 迷你坏坏) | 1.5千次下载 | v1.0.0

## 概述

对指定代码进行全面审查，包含规范性检查、Bug检测、性能优化建议和可读性评估。

## 审查维度

### 1. 代码规范性检查
- 命名规范（变量、函数、类名）
- 代码格式（缩进、空格、行长度）
- 注释完整性
- 文件组织结构

### 2. Bug 检测
- 空指针/None 引用风险
- 数组越界
- 资源泄漏（文件句柄、数据库连接）
- 并发安全问题
- 异常处理缺失

### 3. 性能优化建议
- 不必要的循环嵌套
- 重复计算
- 内存使用优化
- 数据库查询优化
- 缓存策略建议

### 4. 可读性评估
- 函数复杂度
- 代码重复度
- 变量命名清晰度
- 逻辑清晰度

## 严重性分级

| 级别 | 说明 | 处理要求 |
|------|------|---------|
| **严重** | 可能导致崩溃或安全漏洞 | 立即修复 |
| **一般** | 潜在问题或不符合最佳实践 | 建议修复 |
| **优化** | 性能和可读性提升 | 按计划处理 |

## 审查报告格式

```markdown
# 代码审查报告

## 概览
- 审查文件数: X
- 发现问题总数: X
- 严重: X | 一般: X | 优化: X

## 严重问题
1. [文件名:行号] 问题描述 → 修复建议

## 一般问题
1. [文件名:行号] 问题描述 → 修复建议

## 优化建议
1. [文件名:行号] 优化建议 → 预期收益
```

## 注意事项
- 审查使用静态分析方法，可能无法检测运行时问题
- 建议结合单元测试和集成测试进行全面质量保障
- 严重问题优先处理，一般问题在重构时处理，优化问题按进度安排
